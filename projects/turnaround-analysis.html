Project Overview

Aircraft turnaround time — the window between landing and next departure — is one of the most operationally complex and cost-sensitive metrics in aviation. Even small delays cascade into schedule disruptions and customer dissatisfaction. This project analyses simulated ground handling data to surface where those delays originate.

Problem Statement

Ground handling involves multiple parallel workstreams that must all complete before an aircraft can depart:

  • Passenger deboarding and boarding
  • Baggage offload and loading
  • Catering and cabin cleaning
  • Fuelling and technical checks
  • Cargo handling

A delay in any one of these creates a bottleneck. Using logged timestamp data, this analysis identifies which steps most frequently cause the turnaround to exceed target.

Code Preview

Core analysis script — loading data, computing delays, and generating visualisations.

turnaround_analysis.py Python 
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# Load ground handling event data
df = pd.read_csv('ground_handling_data.csv', parse_dates=['start_time', 'end_time'])

# Calculate duration for each task
df['duration_mins'] = (df['end_time'] - df['start_time']).dt.total_seconds() / 60

# Compute delay: actual vs target duration
df['delay_mins'] = df['duration_mins'] - df['target_duration']
df['is_delayed'] = df['delay_mins'] > 0

# Identify most common bottleneck tasks
bottlenecks = (
    df[df['is_delayed']]
    .groupby('task')['delay_mins']
    .agg(['mean', 'count'])
    .rename(columns={'mean': 'avg_delay', 'count': 'frequency'})
    .sort_values('avg_delay', ascending=False)
)

# Visualise
fig, axes = plt.subplots(1, 2, figsize=(14, 6))
sns.barplot(data=bottlenecks.reset_index(),
            x='avg_delay', y='task', ax=axes[0], palette='Blues_r')
axes[0].set_title('Average Delay by Task (minutes)')

sns.heatmap(df.pivot_table(values='delay_mins',
            index='flight_id', columns='task'),
            cmap='RdYlGn_r', ax=axes[1])
axes[1].set_title('Delay Heatmap by Flight')

plt.tight_layout()
plt.savefig('turnaround_analysis.png', dpi=150, bbox_inches='tight')
plt.show()

Methodology

Data Preparation

Loaded and cleaned timestamped ground handling logs. Parsed datetime columns and handled missing values.

Delay Calculation

Computed actual vs target duration for each ground task. Flagged any task exceeding its target as a delay event.

Bottleneck Ranking

Grouped by task type to find average delay magnitude and frequency — ranking which tasks cause the most disruption.

Visualisation

Generated bar charts and heatmaps to communicate findings clearly to a non-technical audience.

Key Findings

  • Baggage loading was the most frequent source of turnaround delay
  • Catering delays had the highest average delay duration when they occurred
  • Flights in the 08:00–10:00 window showed significantly higher delay rates
  • Proposed a staggered task start protocol to reduce cascade risk
