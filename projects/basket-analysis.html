Project Overview

Market basket analysis answers the question: "What gets bought together?" By uploading a CSV of transaction records, this app automatically mines association rules and surfaces product combinations that co-occur more often than chance would predict.

Useful for cross-selling strategy, store layout, bundling promotions, and inventory planning — all from a simple drag-and-drop data upload.

Three Core Metrics

The app calculates and lets you filter by three standard association rule metrics.

Support
P(A∩B)
How often the item combination appears in all transactions
Confidence
P(B|A)
How likely B is purchased when A is already in the basket
Lift
> 1.0
How much more likely the combo is vs. random co-occurrence

How It Works

Upload CSV

Drop in a transaction file with an OrderID column and an Items column (comma-separated products per order).

Top Products

App immediately shows the 10 most frequently ordered individual products with a bar chart.

Basket Encoding

Transactions are exploded and one-hot encoded into a sparse transaction-item matrix for Apriori processing.

Apriori + Rules

Frequent itemsets are mined at min_support=0.01, then association rules generated with lift threshold ≥ 1.

Interactive Explore

Filter top-N rules, choose your metric (support/confidence/lift), and plot any two metrics against each other on a scatter chart sized by support.

Source Code — app.py

Full application code. Clone the repo and run it in two commands.

app.py Python · Streamlit 
import streamlit as st
import pandas as pd
from mlxtend.frequent_patterns import apriori, association_rules
import plotly.express as px

st.set_page_config(page_title="Market Basket Analysis", layout="wide")
st.title("Market Basket Analysis App")
st.write("Upload your transaction CSV file to generate association rules.")

uploaded_file = st.file_uploader("Upload CSV File", type=["csv"])

if uploaded_file:
    df = pd.read_csv(uploaded_file)
    st.success("File uploaded successfully!")

    st.subheader("Data Preview")
    st.dataframe(df)

    order_col = st.selectbox("Select Order ID Column", options=df.columns)
    item_col  = st.selectbox("Select Item Column",     options=df.columns)

    # Top 10 most ordered products
    st.subheader("Top 10 Most Ordered Products")
    exploded_df  = df.assign(Items=df["Items"].str.split(", ")).explode("Items")
    top_products = exploded_df["Items"].value_counts().head(10)
    st.dataframe(top_products.reset_index().rename(columns={"index":"Product","Items":"Order Count"}))
    st.bar_chart(top_products.sort_values(ascending=True))

    # One-hot encode into basket matrix
    basket = (
        exploded_df.assign(value=1)
        .pivot_table(index="OrderID", columns="Items", values="value", fill_value=0)
        .astype(bool)
    )

    # Apriori
    frequent_itemsets = apriori(basket, min_support=0.01, use_colnames=True)

    number = st.number_input("Number of top rules to show",
                             min_value=1, max_value=1000, value=10, step=1)

    rules     = association_rules(frequent_itemsets, metric="lift", min_threshold=1)
    top_rules = rules.sort_values("support", ascending=False).head(number)

    # Clean frozensets for display
    top_rules["antecedents"] = top_rules["antecedents"].apply(lambda x: ", ".join(list(x)))
    top_rules["consequents"] = top_rules["consequents"].apply(lambda x: ", ".join(list(x)))
    top_rules = top_rules[["antecedents","consequents","support","confidence","lift"]]

    # Metric selector
    metric = st.selectbox("Select Metric", options=["support","lift","confidence"])
    st.subheader(f"Top Product Combinations by {metric}")
    st.dataframe(top_rules[["antecedents","consequents",metric]])

    # Scatter plot — any two metrics
    x_axis = st.selectbox("X-Axis Metric", options=["support","lift","confidence"])
    y_axis = st.selectbox("Y-Axis Metric", options=["support","lift","confidence"])
    fig = px.scatter(
        top_rules, x=x_axis, y=y_axis, size="support",
        hover_data=["antecedents","consequents"],
        title=f"{x_axis.capitalize()} vs {y_axis.capitalize()}"
    )
    st.plotly_chart(fig, use_container_width=True)
