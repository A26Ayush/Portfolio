Project Overview

Seasonal retail is a forecasting challenge: order too much and you're left with clearance markdowns; order too little and you miss peak-season revenue. This project applies time-series techniques to historical sales data to generate more reliable demand forecasts for seasonal product categories.

Problem Statement

Seasonal product categories face extreme demand volatility driven by:

  • Holiday peaks and post-season troughs
  • Weather-dependent buying patterns
  • Promotional events that spike and distort baseline demand
  • Lead times that require orders to be placed weeks in advance

Without a structured forecasting approach, buyers rely on intuition — leading to costly overstock and missed sales. This model brings a data-driven process to that decision.

Code Preview

demand_forecast.py Python 
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
from statsmodels.tsa.seasonal import seasonal_decompose

# Load historical sales data
df = pd.read_csv('retail_sales.csv', parse_dates=['date'], index_col='date')
df = df.sort_index()

# Seasonal decomposition
result = seasonal_decompose(df['units_sold'], model='additive', period=52)

# Moving average forecast (4-week and 12-week)
df['ma_4w']  = df['units_sold'].rolling(window=4).mean()
df['ma_12w'] = df['units_sold'].rolling(window=12).mean()

# Simple trend extrapolation for next 8 weeks
last_trend = result.trend.dropna().iloc[-1]
trend_slope = result.trend.dropna().diff().mean()
forecast_weeks = 8
forecast_index = pd.date_range(df.index[-1], periods=forecast_weeks+1, freq='W')[1:]
forecast_values = [last_trend + trend_slope * i for i in range(1, forecast_weeks+1)]
forecast = pd.Series(forecast_values, index=forecast_index)

# Plot
fig, axes = plt.subplots(3, 1, figsize=(14, 10))
df['units_sold'].plot(ax=axes[0], label='Actual Sales', color='#4f8ef7')
df['ma_4w'].plot(ax=axes[0], label='4-Week MA', color='#7c5cfc', linestyle='--')
df['ma_12w'].plot(ax=axes[0], label='12-Week MA', color='#28c840', linestyle='--')
forecast.plot(ax=axes[0], label='8-Week Forecast', color='#ff6b6b', linestyle=':')
axes[0].set_title('Demand Forecast with Moving Averages')
axes[0].legend()

result.seasonal.plot(ax=axes[1], color='#4f8ef7')
axes[1].set_title('Seasonal Component')

result.resid.plot(ax=axes[2], color='#7c5cfc')
axes[2].set_title('Residuals')

plt.tight_layout()
plt.savefig('demand_forecast.png', dpi=150, bbox_inches='tight')
plt.show()

Methodology

Data Extraction

Pulled 2 years of weekly sales data per SKU from SQL database. Cleaned missing weeks and promotional outliers.

Seasonal Decomposition

Applied additive decomposition to separate trend, seasonality, and residual components from the sales signal.

Forecast Generation

Combined 4-week and 12-week moving averages with trend extrapolation to produce an 8-week forward demand estimate.

Accuracy Validation

Compared forecast against actuals using MAE and MAPE. Iterated on window sizes to minimise error.

Key Outcomes

  • Reduced forecast error vs. naive same-week-last-year method by ~22%
  • Identified a consistent 3-week demand spike prior to key holiday periods
  • Model outputs formatted as a buyer-ready order recommendation report in Excel
  • Flagged 4 SKUs where promotional pricing distorted baseline — recommended exclusion from standard forecast
